## Conclusión
Aprendí a utilizar la consola de comandos (cmd) para interactuar directamente con un Gestor de Bases de Datos Relacionales sin depender de una interfaz gráfica. Comprendí de manera práctica la jerarquía entre base de datos, tabla, registro y campo, así como la importancia de elegir los tipos de datos correctos para optimizar la información.

Dificultades encontradas:
Sintaxis estricta y comandos en la terminal, como pequeños errores de dedo que invalidaban la instruccion
Manejo de caracteres especiales

Cómo las resolví:
Presté mayor atención a la sintaxis y al uso obligatorio del punto y coma ; al final de cada instrucción antes de dar Enter.
Verifiqué de forma constante la información ejecutando consultas con SELECT * FROM después de cada modificación o eliminación para comprobar visualmente que las operaciones se aplicaran de manera correcta.
